<h1>Find the latest in a set</h1>

```java
Optional<Course> latestCourse
  = courses.stream()
           .max((course1, course2) -> course1.getEndDate().compareTo(course2.getEndDate()));

// Handle the optional result
latestCourse.ifPresent(course -> System.out.println("Latest course: " + course));

// Or if you want to handle the case where no course is found
latestCourse.orElseThrow(() -> new RuntimeException("No courses available"));

```
