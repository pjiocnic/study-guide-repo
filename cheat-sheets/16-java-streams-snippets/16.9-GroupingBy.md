<h1>16.9-GroupingBy</h1>

## Example

```java
// Group courses by name
Map<String, List<Course>> groupedCourses = courses.stream()
        .collect(Collectors.groupingBy(Course::getName));

// Update end dates
groupedCourses.forEach((courseName, courseList) -> {
    // Sort courses by start date in descending order (latest course first)
    courseList.sort(Comparator.comparing(Course::getStartDate).reversed());

    // Get the latest course
    Course latestCourse = courseList.get(0);
    latestCourse.setEndDate(null); // Ensure the latest course has no end date

    // Set today's date as the end date for all other courses with null end date
    LocalDate today = LocalDate.now();
    courseList.stream()
            .skip(1) // Skip the latest course
            .filter(course -> course.getEndDate() == null) // Only update courses with null end date
            .forEach(course -> course.setEndDate(today));
});

```
