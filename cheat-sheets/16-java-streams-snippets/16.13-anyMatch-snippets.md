
### 1. Substring Matching with anyMatch

```java
List<String> listA = Arrays.asList("app", "ban", "cher");
List<String> listB = Arrays.asList("apple", "banana", "cherry");

boolean found = listA.stream()
    .anyMatch(a -> listB.stream().anyMatch(b -> b.contains(a)));

System.out.println("Found: " + found);
```

### 2. Debugging anyMatch

```java
List<String> listA = Arrays.asList("apple", "banana", "cherry");
List<String> listB = Arrays.asList("grape", "banana", "orange");

boolean found = listA.stream()
    .peek(item -> System.out.println("Checking: " + item)) // Debug each item in List A
    .anyMatch(item -> {
        boolean result = listB.contains(item);
        System.out.println("Does " + item + " exist in listB? " + result);
        return result;
    });

System.out.println("Found: " + found);
```
