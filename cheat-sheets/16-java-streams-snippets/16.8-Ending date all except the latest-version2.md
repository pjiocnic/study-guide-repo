### Main Logic: Limit Problem to Lecturers

#### Updated Implementation

```java
import java.time.LocalDate;
import java.util.*;
import java.util.stream.Collectors;

public class Main {
    public static void main(String[] args) {
        // Create tutors
        Tutor lecturer1 = new Tutor("Lecturer 1", TutorType.LECTURER);
        Tutor lecturer2 = new Tutor("Lecturer 2", TutorType.LECTURER);
        Tutor ta = new Tutor("TA 1", TutorType.TA);

        // Create courses
        List<Course> courses = List.of(
                new Course("Course 1", LocalDate.of(2024, 1, 1), null, List.of(lecturer1, lecturer2, ta)),
                new Course("Course 2", LocalDate.of(2024, 2, 1), null, List.of(lecturer1)),
                new Course("Course 3", LocalDate.of(2024, 3, 1), null, List.of(lecturer2)),
                new Course("Course 4", LocalDate.of(2024, 4, 1), null, List.of(lecturer1)),
                new Course("Course 5", LocalDate.of(2024, 5, 1), null, List.of(lecturer2)),
                new Course("Course 6", LocalDate.of(2024, 6, 1), null, List.of(lecturer1, lecturer2))
        );

        // Filter courses for LECTURERs and group by lecturer
        Map<Tutor, List<Course>> lecturerToCourses = courses.stream()
                .flatMap(course -> course.getTutors().stream()
                        .filter(tutor -> tutor.getType() == TutorType.LECTURER) // Only include LECTURERs
                        .map(tutor -> Map.entry(tutor, course))) // Pair lecturer with their course
                .collect(Collectors.groupingBy(
                        Map.Entry::getKey,
                        Collectors.mapping(Map.Entry::getValue, Collectors.toList())
                ));

        // End-date all courses except the latest for each lecturer
        LocalDate today = LocalDate.now();
        lecturerToCourses.forEach((lecturer, lecturerCourses) -> {
            lecturerCourses.stream()
                    .sorted(Comparator.comparing(Course::getStartDate).reversed()) // Sort by startDate descending
                    .skip(1) // Skip the latest course
                    .filter(course -> course.getEndDate() == null) // Only update courses without an end date
                    .forEach(course -> course.setEndDate(today)); // Set end date
        });

        // Print results
        courses.forEach(System.out::println);
    }
}
```

---

### Key Updates:
1. **Filter by `TutorType.LECTURER`**:
   - The `filter(tutor -> tutor.getType() == TutorType.LECTURER)` ensures that only courses taught by lecturers are considered for end-dating.

2. **Retain Logic for Grouping**:
   - Uses the same `flatMap` and `groupingBy` approach to map lecturers to their courses.

3. **Exclude TAs**:
   - TAs (`TutorType.TA`) are not included in the logic and won’t influence the end-dating process.

4. **Shared Courses**:
   - If a course is taught by multiple lecturers, it’s considered for each lecturer individually.
