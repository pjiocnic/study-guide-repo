
# Oracle Team Scores Pivot Setup

This project contains a complete Oracle SQL setup to demonstrate how to **pivot row data into columns** using the `PIVOT` clause. It includes best practices such as sequence-based primary keys, indexing, triggers, and administrative timestamp columns.

---

## 📁 Files Included

| File Name              | Purpose |
|------------------------|---------|
| `01_create_sequence.sql` | Creates a sequence `team_scores_seq` for generating primary keys |
| `02_create_table.sql`    | Creates the `team_scores` table with admin columns |
| `03_create_trigger.sql`  | Adds a `BEFORE INSERT` trigger to auto-fill `SEQ`, `CREATED_AT`, and `UPDATED_AT` |
| `04_create_index.sql`    | Adds an index on `(TEAM, GAME)` for query performance |
| `05_insert_data.sql`     | Sample data inserts for 3 teams and 4 games |
| `06_pivot_query.sql`     | Query to pivot rows into columns using Oracle SQL `PIVOT` |

## 🛠️ How to Use

### Option 1: SQL Developer
1. Open SQL Developer.
2. Connect to your Oracle database.
3. Open and run each script in the order listed above.
4. Execute `06_pivot_query.sql` to view the pivoted table output.

### Option 2: SQL\*Plus or SQLcl
```bash
sqlplus user/password@your_db @01_create_sequence.sql
sqlplus user/password@your_db @02_create_table.sql
sqlplus user/password@your_db @03_create_trigger.sql
sqlplus user/password@your_db @04_create_index.sql
sqlplus user/password@your_db @05_insert_data.sql
sqlplus user/password@your_db @06_pivot_query.sql
```

---

## 📌 Notes

- The `PIVOT` clause requires known values in the `IN` clause. This example uses `'GAME1'` to `'GAME4'`.
- If more games are added in the future, you will need to update the `PIVOT` query.
- NULL will appear where data is missing (e.g., `TEAM3` did not play `GAME4`).
