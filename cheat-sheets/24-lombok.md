# How to look for generated code?

To see the code generated by Lombok for `equals` and `hashCode` methods, you can use one of the following approaches:

---

### **1. Use a decompiler to inspect compiled bytecode**
1. **Add Lombok annotations**:
   Annotate your class with `@EqualsAndHashCode` (or any other Lombok annotation you use).
   ```java
   import lombok.EqualsAndHashCode;

   @EqualsAndHashCode
   public class MyClass {
       private int id;
       private String name;
   }
   ```

2. **Compile your code**:
   Use your IDE or `javac` to compile the code.

3. **Decompile the class file**:
   - Use a decompiler (e.g., [JD-GUI](https://github.com/java-decompiler/jd-gui), [Fernflower](https://github.com/JetBrains/intellij-community/tree/master/plugins/java-decompiler/engine), or any IDE with decompilation support like IntelliJ or Eclipse).
   - Open the compiled `.class` file to view the generated `equals` and `hashCode` methods.

---

### **2. Use Lombok's `delombok` feature**
`delombok` allows you to generate plain Java source code with all the Lombok annotations replaced by their generated code.

1. **Run `delombok` using Maven or Gradle**:
   - **Maven**:
     Add the `lombok-maven-plugin` to your `pom.xml`:
     ```xml
     <build>
         <plugins>
             <plugin>
                 <groupId>org.projectlombok</groupId>
                 <artifactId>lombok-maven-plugin</artifactId>
                 <version>1.18.28.0</version>
             </plugin>
         </plugins>
     </build>
     ```
     Run:
     ```bash
     mvn lombok:delombok
     ```
   - **Gradle**:
     Add the Lombok Delombok task to your `build.gradle`:
     ```groovy
     tasks.register('delombok', JavaExec) {
         main = 'lombok.launch.Main'
         classpath = configurations.compileClasspath
         args = ['delombok', 'src', '-d', 'delomboked']
     }
     ```
     Run:
     ```bash
     ./gradlew delombok
     ```

2. **Inspect the delomboked source files**:
   Check the output folder (`delomboked` or as specified) for the plain Java files with the `equals` and `hashCode` methods.

---

### **3. Use your IDE's Lombok plugin**
Modern IDEs like IntelliJ IDEA and Eclipse with Lombok plugins installed can often preview the generated code.
- In **IntelliJ IDEA**:
  - Right-click the class and choose **Show Generated Code** or navigate to **View > Show Lombok Annotations as Java**.
- In **Eclipse**:
  - Enable Lombok support in the Preferences, and check the generated methods under outline view.

---

### Sample Generated Code for `@EqualsAndHashCode`
For a class like:
```java
@EqualsAndHashCode
public class MyClass {
    private int id;
    private String name;
}
```
The generated methods might look like this:
```java
@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (o == null || getClass() != o.getClass()) return false;
    MyClass myClass = (MyClass) o;
    return id == myClass.id && Objects.equals(name, myClass.name);
}

@Override
public int hashCode() {
    return Objects.hash(id, name);
}
```

These methods are automatically created for you unless you override them explicitly.
