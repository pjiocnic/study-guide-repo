### **About This Template**

An example to demonstrate how to show base64 image

---

```html
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <title>Display Base64 Image</title>
</head>

<body>
  <h1>My Base64 Image</h1>
  <img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA..." alt="Base64 Image" />
</body>

</html>
```
