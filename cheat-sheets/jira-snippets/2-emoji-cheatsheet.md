Great question! Here's how you can find and use emojis in **Jira** — whether you're using **Jira Cloud**, **Jira Server**, or **Data Center**:

---

## 🧭 1. **Use Jira’s Built-in Emoji Picker (Cloud/Web UI)**

If you're using **Jira Cloud**, it has a **native emoji picker**:

### ➤ Steps:
1. Click inside any text field (description, comment, etc.)
2. Type `:` (colon) to open the emoji picker.
3. Start typing the name of the emoji, like `:check:` or `:rocket:`
4. Select from the dropdown

✅ Example:
Typing `:check:` gives ✅
Typing `:chart_with_upwards_trend:` gives 📈

---

## 🧰 2. **Manually Paste Unicode Emojis**

You can **copy-paste emojis from**:
- [https://emojipedia.org/](https://emojipedia.org/)
- Or use the shortcuts below

### 💻 Emoji Shortcut on Desktop

| OS | Shortcut |
|----|----------|
| **Mac** | `Control + Command + Space` |
| **Windows 10/11** | `Windows + .` (period) or `Windows + ;` (semicolon) |
