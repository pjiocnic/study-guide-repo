# Financial Sentiment Classification (RoBERTa)

## Structure
- `classification_template_roberta.py` – Reusable script to load RoBERTa model and metrics.
- `financial_classifier_flat.ipynb` – Colab demo for 4-class classification.
- `financial_classifier_two_stage.ipynb` – Colab demo for sentiment + relevance two-stage classification.

## Labels
- `positive`
- `positive_irrelevant`
- `negative`
- `inconclusive`

You can use your own financial dataset or simulate using sample sentences.
