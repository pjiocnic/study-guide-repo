### 5. What does "transfer learning" mean?

---

### ❓ Question

What does *transfer learning* refer to in the context of Transformers?

#### Choices:

1. **Transferring the knowledge of a pretrained model to a new model by training it on the same dataset.**
   ❌ *Incorrect.*

   > That would be two versions of the same model.

2. **✅ Transferring the knowledge of a pretrained model to a new model by initializing the second model with the first model's weights.**
   ✔️ *Correct.*

   > When the second model is trained on a new task, it *transfers* the knowledge of the first model.

3. **Transferring the knowledge of a pretrained model to a new model by building the second model with the same architecture as the first model.**
   ❌ *Incorrect.*

   > The architecture is just the way the model is built; there is no knowledge shared or transferred in this case.

### 7. Select the sentence that best describes the terms "model", "architecture", and "weights".

### ❓ Question

Which of the following best describes the relationship between a model’s architecture and its weights?

#### Choices:

1. **If a model is a building, its architecture is the blueprint and the weights are the people living inside.**
   ❌ *Incorrect.*

   > In this metaphor, the weights would more accurately be the **bricks and materials** used to construct the building.

2. **An architecture is a map to build a model and its weights are the cities represented on the map.**
   ❌ *Incorrect.*

   > This metaphor is flawed because a map represents a **single fixed reality**, whereas a given architecture can produce many different models based on the weights.

3. **✅ An architecture is a succession of mathematical functions to build a model and its weights are those functions’ parameters.**
   ✔️ *Correct.*

   > The same architecture (set of functions) can be used to build different models by using different **parameters (weights)**.

### 8. Which of these types of models would you use for completing prompts with generated text?

### ❓ Question

Which type of model is best suited for generating text from a prompt?

#### Choices:

1. **An encoder model**
   ❌ *Incorrect.*

   > Encoder models generate representations of entire input sequences, which are more useful for tasks like classification.

2. **✅ A decoder model**
   ✔️ *Correct.*

   > Decoder models are specifically designed for **text generation from a prompt**.

3. **A sequence-to-sequence model**
   ❌ *Incorrect.*

   > These models are better for tasks like **translation or summarization**, where you generate a sequence in direct relation to an input sequence.


### 9. Which of those types of models would you use for summarizing texts?

### ❓ Question

Which type of model is best suited for **summarization**?

#### Choices:

1. **An encoder model**
   ❌ *Incorrect.*

   > Encoder models generate representations of input sequences, useful for tasks like **classification**, but not for generating summaries.

2. **A decoder model**
   ❌ *Incorrect.*

   > Decoder models can generate output text, but they **lack the full context** of the input, making them less ideal for summarization tasks.

3. **✅ A sequence-to-sequence model**
   ✔️ *Correct.*

   > Sequence-to-sequence models are **perfectly suited** for summarization, where the output sequence is generated in relation to a full input sequence.

### 10. Which of these types of models would you use for classifying text inputs according to certain labels?

### ❓ Question

Which type of model is best suited for **text classification**?

#### Choices:

1. **✅ An encoder model**
   ✔️ *Correct.*

   > Encoder models generate contextual representations of the full sentence, making them ideal for **classification tasks**.

2. **A decoder model**
   ❌ *Incorrect.*

   > Decoder models are designed for **text generation**, not for extracting labels from input sequences.

3. **A sequence-to-sequence model**
   ❌ *Incorrect.*

   > These models are better for tasks like **translation or summarization**, where the output is a new sequence of text rather than a label.

### 11. What possible source can the bias observed in a model have?

### ❓ Question

Why might a model exhibit biased behavior?

#### Choices:

1. **✅ The model is a fine-tuned version of a pretrained model and it picked up its bias from it.**
   ✔️ *Correct.*

   > When applying **Transfer Learning**, the bias present in the **pretrained model** often carries over to the fine-tuned version.

2. **✅ The data the model was trained on is biased.**
   ✔️ *Correct.*

   > This is the most **obvious** source of bias — if your training data is biased, the model will learn that bias.

3. **✅ The metric the model was optimizing for is biased.**
   ✔️ *Correct.*

   > Even the **training objective** can introduce bias. Models will faithfully optimize for whatever metric is chosen, regardless of fairness or social impact.
