### 🌳 Node Purity in Decision Trees

In decision trees, **node purity** refers to the degree to which a node contains data points belonging to **only one class**.
- A **pure node** contains data points **from a single class**.
- An **impure node** contains a **mix of classes**.
📚 *Sources: [1](https://en.wikipedia.org/wiki/Decision_tree), [2](https://quantdare.com/decision-trees-gini-vs-entropy/), [3](https://towardsdatascience.com/decision-trees-explained-entropy-information-gain-gini-index-ccp-pruning-4d78070db36c/)*

---

### 🔍 Elaboration

- **Goal**:
  Decision tree algorithms aim to split data such that **each node becomes increasingly pure**.
  📚 *Sources: [1](https://en.wikipedia.org/wiki/Decision_tree), [3](https://towardsdatascience.com/decision-trees-explained-entropy-information-gain-gini-index-ccp-pruning-4d78070db36c/)*

- **Leaf Nodes**:
  A well-trained tree has **pure leaf nodes** (i.e., all data points in the leaf belong to one class).
  📚 *Sources: [1](https://en.wikipedia.org/wiki/Decision_tree), [4](https://medium.com/@marjorieivy/machine-learning-model-decision-trees-part-1-adc97a2abdf6)*

---

### 📐 Measures of Purity

- **Gini Impurity**
  - Measures the probability of misclassification.
  - **Lower Gini = Higher Purity**
  📚 *Sources: [5](https://www.numberanalytics.com/blog/top-7-essential-stats-gini-impurity-decision-trees), [6](https://niranjanappaji.medium.com/a-tale-of-two-metrics-gini-impurity-and-entropy-in-decision-tree-algorithms-7f61d46baacc)*

- **Entropy**
  - Measures the **randomness/uncertainty** in class distribution.
  - **Lower Entropy = Higher Purity**
  📚 *Sources: [7](https://medium.com/@arpita.k20/gini-impurity-and-entropy-for-decision-tree-68eb139274d1), [8](https://www.baeldung.com/cs/impurity-entropy-gini-index)*

---

### ⚖️ Relationship to Splitting

Decision trees use impurity measures to find the **best feature to split on** at each node.
- The algorithm **chooses the split** that **maximizes node purity** (i.e., reduces impurity the most).
📚 *Sources: [3](https://towardsdatascience.com/decision-trees-explained-entropy-information-gain-gini-index-ccp-pruning-4d78070db36c/), [5](https://www.numberanalytics.com/blog/top-7-essential-stats-gini-impurity-decision-trees)*

---

### 💡 Example

Suppose you're classifying **whether a customer will purchase a product** (`Yes`/`No`):

- A **pure node** contains only `"Yes"` responses.
- An **impure node** contains both `"Yes"` and `"No"` labels.
📚 *Sources: [1](https://en.wikipedia.org/wiki/Decision_tree), [3](https://towardsdatascience.com/decision-trees-explained-entropy-information-gain-gini-index-ccp-pruning-4d78070db36c/)*
