### 🔍 What is Cross-Validation in ML?

> **Cross-validation** is a statistical technique used to **evaluate the generalizability** of a machine learning model by testing it on **multiple different splits** of the dataset.

It helps answer:
> "How well will my model perform on data it hasn't seen before?"

---

### 🤔 Why Use Cross-Validation?

- A **single train-test split** (e.g., with `train_test_split`) may **give different results** depending on the random seed.
- This makes the score **unstable** and **unreliable** for assessing model performance.
- Cross-validation gives a more **robust and fair estimate** of model performance.

---

### 🔁 What is K-Fold Cross-Validation?

> In **k-fold cross-validation**, the dataset is split into **k equal-sized parts (folds)**. The model is trained and evaluated **k times**, each time using a different fold as the test set and the remaining `k-1` folds as the training set.

#### Example (k=5):
1. Train on folds 2–5, test on fold 1
2. Train on folds 1, 3–5, test on fold 2
3. ... and so on up to fold 5

- This results in **k different models** and **k different scores**.
- The **final score is the mean of these k scores**.

---

### 🔄 Characteristics:

- **Training sets overlap**, but **test sets do not**.
- This gives the model multiple chances to be evaluated, reducing **random variance** from just one split.

---

### ⚙️ Choosing the Number of Folds (`k`)

| k value | Test Size Per Fold | When to Use |
|---------|--------------------|-------------|
| 3       | 33%                | Small datasets |
| 5       | 20%                | ✅ Common standard |
| 10      | 10%                | ✅ More robust, reduces outlier impact |

> ✅ **Higher k** → more training data per fold, but longer training time.
> ✅ **Lower k** → faster, but less stable estimate.

---

### 🛠 How to Implement Cross-Validation

Using `cross_val_score()` from scikit-learn:

```python
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LinearRegression
import numpy as np

# Perform 5-fold cross-validation using negative MSE as score
scores = cross_val_score(LinearRegression(), X, y, scoring='neg_mean_squared_error', cv=5)

# Convert negative MSE to RMSE
rmse_scores = (-scores) ** 0.5

# Print individual and average scores
print("Fold-wise RMSE scores:", rmse_scores)
print("Mean RMSE:", rmse_scores.mean())
```
