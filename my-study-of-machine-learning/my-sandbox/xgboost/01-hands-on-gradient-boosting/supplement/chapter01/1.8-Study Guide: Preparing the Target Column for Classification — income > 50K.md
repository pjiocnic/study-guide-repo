# 🧾 Study Guide: Preparing the Target Column for Classification — `income > 50K`

---

## 🎯 Objective

> Predict whether a person earns **more than $50,000 per year** using demographic and work-related features.

The target column is:
```python
df_census['income']
```

### 🔸 Original Values:
- `<=50K`
- `>50K`

These are **categorical** and need to be converted to **numeric format** before using them in machine learning models.

---

## 🧠 Step-by-Step Breakdown

### 🧪 Step 1: One-Hot Encode the Target

We use `pd.get_dummies()` to convert the `income` column (and any other categorical columns) into numerical **binary indicator columns**:

```python
df_census = pd.get_dummies(df_census)
```

This converts the original `income` column into:

| income_<=50K | income_>50K |
|--------------|-------------|
| 1            | 0           |
| 0            | 1           |
| 1            | 0           |
| ...          | ...         |

---

### ❓Why Two Columns?

Each row gets:
- `income_<=50K = 1` if they earn $50K or less
- `income_>50K = 1` if they earn more than $50K

These columns are **complementary** (if one is 1, the other is 0). So:

```python
income_>50K = 1 - income_<=50K
```

---

### ⚠️ Step 2: Drop One of the Dummy Columns

Keeping both creates **redundancy** and leads to the **dummy variable trap** (perfect multicollinearity), which can:
- Confuse models (especially linear models)
- Lead to unstable coefficient estimates

We solve this by **dropping one of the two columns**:

```python
df_census = df_census.drop('income_<=50K', axis=1)
```

Now we only keep:

```python
df_census['income_>50K']
```

---

## ✅ Final Setup

| Column              | Meaning                     |
|---------------------|-----------------------------|
| `income_>50K = 1`   | Earns more than $50K        |
| `income_>50K = 0`   | Earns $50K or less          |

You can now treat `income_>50K` as your **target variable** for binary classification.

---

## 🛠 Use in a Classification Model

```python
from sklearn.linear_model import LogisticRegression

# Set target and features
y = df_census['income_>50K']
X = df_census.drop('income_>50K', axis=1)

# Train logistic regression model
model = LogisticRegression()
model.fit(X, y)
```

---

## 📌 TL;DR

| Step | Action |
|------|--------|
| 1️⃣  | Use `pd.get_dummies()` to encode categorical target |
| 2️⃣  | Drop one dummy column (to avoid multicollinearity) |
| 3️⃣  | Use the remaining column (e.g., `income_>50K`) as your target |
| ✅  | You now have a clean **binary classification problem**! |
