# 📘 Study Guide: Regressors vs. Classifiers
*With Real-World Examples: Bike Rentals & Titanic Dataset*

---

## ✅ What Are They?

| Term        | Definition |
|-------------|------------|
| **Regressor** | A machine learning model that predicts **continuous numerical values** (e.g., price, temperature, bike rentals). |
| **Classifier** | A machine learning model that predicts **categories or class labels** (e.g., survived/died, spam/ham, healthy/sick). |

---

## 🧠 How to Know Which One to Use

| Ask Yourself...                         | If the answer is: | Use a...     |
|-----------------------------------------|--------------------|--------------|
| Am I predicting a **number**?           | Yes                | ✅ Regressor |
| Am I predicting a **category or class**?| Yes                | ✅ Classifier |

---

## 📊 Examples

| Use Case                           | Problem Type   | Model Type   |
|-----------------------------------|----------------|--------------|
| Predict house prices              | Regression     | Regressor    |
| Predict daily bike rentals        | Regression     | Regressor    |
| Predict survival on the Titanic   | Classification | Classifier   |
| Predict if email is spam          | Classification | Classifier   |

## 🚴‍♂️ Regressor Example: Bike Rentals

### 🧪 Goal:
> Predict the **number of bike rentals** (`cnt`) using features like weather, temperature, season, and day type.

### 🎯 Target: `cnt`
A numeric column → requires a **regressor**.

### ✅ Recommended Regressors:
| Algorithm         | scikit-learn Class |
|------------------|---------------------|
| Linear Regression | `LinearRegression()` |
| Decision Tree     | `DecisionTreeRegressor()` |
| Random Forest     | `RandomForestRegressor()` |
| XGBoost           | `XGBRegressor()` |

### 🧪 Code Sample:
```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

X = df_bikes.drop(columns=['cnt', 'casual', 'registered'])  # remove leakage
y = df_bikes['cnt']

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=2)
model = LinearRegression().fit(X_train, y_train)

y_pred = model.predict(X_test)
rmse = mean_squared_error(y_test, y_pred, squared=False)
r2 = r2_score(y_test, y_pred)

print(f"RMSE: {rmse:.2f}, R² Score: {r2:.4f}")
```

### 🔍 Output Example:
```
RMSE: 898.21
R² Score: 0.7933
```

## 🛳️ Classifier Example: Titanic Survival

### 🧪 Goal:
> Predict whether a passenger **survived** the Titanic disaster (`Survived` = 0 or 1), based on age, gender, class, etc.

### 🎯 Target: `Survived`
A binary column → requires a **classifier**.

### ✅ Recommended Classifiers:
| Algorithm         | scikit-learn Class           |
|------------------|-------------------------------|
| Logistic Regression | `LogisticRegression()`       |
| Decision Tree       | `DecisionTreeClassifier()`   |
| Random Forest       | `RandomForestClassifier()`   |
| XGBoost             | `XGBClassifier()`            |

### 🧪 Code Sample:
```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

titanic = pd.read_csv("https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv")
titanic['Sex'] = titanic['Sex'].map({'male': 0, 'female': 1})
features = ['Pclass', 'Sex', 'Age', 'SibSp', 'Parch', 'Fare']
titanic = titanic[features + ['Survived']].dropna()

X = titanic[features]
y = titanic['Survived']

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=2)
clf = RandomForestClassifier().fit(X_train, y_train)

y_pred = clf.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.4f}")
```

### 🔍 Output Example:
```
Accuracy: 0.8258
```

## 🔍 Output Differences

| Aspect           | Regressor                        | Classifier                     |
|------------------|----------------------------------|--------------------------------|
| **Output**       | Continuous value (e.g., 4503.8)  | Class label (e.g., 0 or 1)     |
| **Goal**         | Predict quantity                | Predict class membership       |
| **Metrics**      | RMSE, R² Score                  | Accuracy, Precision, Recall    |
| **Visual Tools** | Predicted vs Actual Scatter     | Confusion Matrix, ROC Curve    |

---

## 🧮 Evaluation Metrics

| Metric     | Type          | Purpose |
|------------|---------------|---------|
| **RMSE**   | Regression    | Avg prediction error |
| **R² Score** | Regression    | % of variance explained |
| **Accuracy** | Classification | % correct predictions |
| **Precision/Recall/F1** | Classification | Balance correctness and completeness |
