## 🔍 What It Means:

**“BERT is fine-tuned by adding a classification head on top of the \[CLS] token output.”**

Let’s break it down:

### ✅ Step-by-Step Explanation

### **1. BERT’s Output**

When you pass a sentence into BERT, it returns a **hidden state (vector)** for each token in the input.

* For example, input:
  `"This is great"` → tokens: `[CLS] This is great [SEP]`
* BERT returns a **vector for each token**, including the special token `[CLS]` (stands for **Classification**).

💡 **The `[CLS]` token is designed to capture the "summary" of the whole sentence**.

---

### **2. Classification Head**

The **classification head** is a **simple feedforward neural network** (often a single linear layer) added **on top of the \[CLS] vector**.

* Input: `[CLS]` hidden state (shape = `[batch_size, hidden_dim]`, typically 768)
* Output: logits (raw scores) → Softmax → Class probabilities

```python
# Pseudo PyTorch code:
logits = LinearLayer(hidden_state_cls)  # shape → [batch_size, num_labels]
probs = Softmax(logits)                 # shape → [batch_size, num_labels]
```

So instead of training BERT from scratch, you:

* Keep BERT’s pre-trained weights
* Add a classification head
* Fine-tune on your labeled dataset (e.g., for sentiment, spam, emotion, etc.)

---

### ✅ Real Example: Sentiment Classification

```python
text = "I love this movie"
input_ids = tokenizer(text, return_tensors="pt")
outputs = model(**input_ids)  # output has hidden_states

# Get [CLS] token representation (position 0)
cls_vector = outputs.last_hidden_state[:, 0, :]  # shape [batch_size, 768]

# Classification head: convert cls_vector → 2 classes (positive, negative)
logits = classifier(cls_vector)
probs = softmax(logits)
```

## 📌 Summary

| Term                | Meaning                                                                 |
| ------------------- | ----------------------------------------------------------------------- |
| `[CLS]` token       | Special token at beginning, used to summarize the input                 |
| Classification head | A small neural network (usually linear) added after `[CLS]` vector      |
| Fine-tuning         | Training BERT + head together on a specific downstream task             |
| Output              | Class probabilities (e.g., positive vs negative, topic categories, etc) |
