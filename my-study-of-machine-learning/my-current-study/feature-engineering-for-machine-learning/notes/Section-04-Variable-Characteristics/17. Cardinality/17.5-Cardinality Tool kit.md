High cardinality poses the following challenges:

1. Variables with too many labels tend to dominate those with only a few labels, particularly in decision tree-based algorithms.
2. High cardinality may introduce noise.
3. Some of the labels may only be present in the training data set and not in the test set, so machine learning algorithms may over-fit to the training set.
4. Some labels may appear only in the test set, leaving the machine learning algorithms unable to perform a calculation over the new (unseen) observation.
   
PROBLEM: Algorithms based on decision trees can be biased towards variables with high cardinality.
