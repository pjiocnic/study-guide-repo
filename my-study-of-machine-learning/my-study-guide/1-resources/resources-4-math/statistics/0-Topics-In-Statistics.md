# Key Areas of Statistics for Machine Learning

## Descriptive Statistics

Useful for general analysis and diagnosing models. This is about summarizing and portraying your data clearly.

* **Averages**: Mean, Median, Mode
* **Spread**: Standard Deviation, Variance, Covariance
* **Plots**: Bar, Line, Pie, Histograms, Error Bars

---

## Probability Distributions

The heart of statistics, defining the shape of event probabilities. You don’t need to learn them all, but a few key ones are:

* Normal
* Binomial
* Gamma
* Log-normal
* Poisson
* Geometric

---

## Probability Theory

Machine learning is grounded in statistical learning, which requires understanding probability concepts:

* Maximum Likelihood Estimation (MLE)
* Central Limit Theorem
* Bayesian Statistics

---

## Hypothesis Testing

Critical in real-world machine learning use cases like model evaluation and A/B testing.

* Significance Level
* Z-Test
* T-Test
* Chi-Square Test
* Sampling

---

## Modelling & Inference

Many machine learning algorithms originated from statistical models.

* Linear Regression
* Logistic Regression
* Polynomial Regression
* Model Residuals
* Model Uncertainty
* Generalised Linear Models (GLMs)
