For learning intermediate-level Python and then transitioning to machine learning, there are some excellent books that offer a good balance between theory and practice. Here are a few recommendations:

### Intermediate Python:
1. **"Fluent Python" by Luciano Ramalho**
   - This book dives deep into Python's more advanced features, such as data structures, functions, object-oriented programming, and metaprogramming. It’s perfect for someone who has a basic understanding of Python and wants to enhance their skills.

2. **"Python Tricks: A Buffet of Awesome Python Features" by Dan Bader**
   - This is a highly readable book that offers tips and tricks to improve Python code quality, efficiency, and readability. It’s filled with practical examples and is suitable for someone looking to go beyond the basics.

### Python for Machine Learning:
1. **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron**
   - A fantastic book for transitioning into machine learning. It covers all the key algorithms and tools (scikit-learn, TensorFlow, Keras) while building a solid foundation in Python. There are practical exercises and real-world examples to get hands-on experience.

2. **"Python Machine Learning" by Sebastian Raschka**
   - This book is a comprehensive guide to machine learning using Python, scikit-learn, and deep learning frameworks like TensorFlow. It’s perfect for someone looking to build machine learning models from scratch and understand the core concepts.

3. **"Deep Learning with Python" by François Chollet**
   - If you're interested in deep learning specifically, this book, written by the creator of Keras, offers an approachable introduction to neural networks and deep learning with Python.

These books should help you build a strong intermediate foundation in Python and guide you into the world of machine learning effectively.
