  * Introduction: Initial setup on Amazon SageMaker Studio environment;
  * DataPrep: Load churn dataset, tranform it on Amazon SageMaker Data Wrangler, and export it to S3;
  * Modeling: Create a XGBoost model using Amazon SageMaker Training Jobs and keep track of each training job with Amazon SageMaker Experiments and also debug our model with Amazon SageMaker Debugger;
  * Evaluation: Check model accuracy with Amazon SageMaker Processing and explainability using Amazon SageMaker Clarify;
  * Deployment: Host our model on Model hosting and batch inference on Batch Transform;
  * Monitoring: Monitor our model for concept drift with SageMaker Model Monitor;
  * Pipelines: Create a Amazon SageMaker Pipelines to run our entire process.
