## ✅ **📘 Books (Hands-on + Theory)**

### 1. **[Feature Engineering for Machine Learning: Principles and Techniques for Data Scientists](https://www.oreilly.com/library/view/feature-engineering-for/9781491953235/)**

**By**: Alice Zheng and Amanda Casari (O’Reilly)

* **Case Studies Included**:

  * Predicting ad click-through rates
  * Fraud detection
  * Recommender systems
* **Strengths**:

  * Real datasets and workflows
  * Includes both domain-driven and statistical features
  * Code examples in Python
* **Ideal for**: Intermediate to advanced practitioners

---

### 2. **[Practical Feature Engineering](https://www.manning.com/books/practical-feature-engineering)**

**By**: Alice Zheng (Manning, MEAP available)

* **Case Study-Based Approach**:

  * Contains full pipelines: data cleanup, transformation, and model integration
  * Reproducible Python projects

---

### 3. **[Data Preparation for Machine Learning](https://machinelearningmastery.com/data-preparation-for-machine-learning/)**

**By**: Jason Brownlee

* Covers:

  * Outlier detection, encoding, transformations
  * Includes small-to-medium size projects with feature crafting

---

## ✅ **🎓 Courses (Project-Based & Case-Driven)**

### 1. **[Feature Engineering by Google Cloud on Coursera](https://www.coursera.org/learn/feature-engineering)**

**Instructor**: Google Cloud AI Team
**Platform**: Coursera

* **What You’ll Learn**:

  * TensorFlow & scikit-learn pipelines
  * Domain-specific transformations (text, images, time series)
  * Real-world tasks (e.g., customer churn, credit scoring)

* **Strengths**: Covers both deep learning and classical ML cases

* **Hands-on**: With Qwiklabs-based notebooks

---

### 2. **[Feature Engineering for Competitive Data Science](https://www.udemy.com/course/feature-engineering-for-machine-learning/)** (Udemy)

**By**: Soledad Galli (Data Scientist, ex-Bank of England)

* **Covers**:

  * Real datasets (housing prices, bank churn, titanic, etc.)
  * Missing value imputation
  * Encoding, discretization, transformation, feature extraction, and selection
* **Strengths**:

  * Each section ends with practical notebook projects
  * Focuses on preparing features for tree-based models like XGBoost
